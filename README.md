# E-Commerce Platform

A full-stack e-commerce application demonstrating Java/Spring backend development with a React frontend.

## Key Features
- Product catalog with search, filtering, sorting and pagination
- User authentication and Google OAuth 2.0
- Shopping cart and order management
- MySQL persistence with Spring Data JPA
- Redis-based caching
- Stripe payment integration
- Responsive frontend
- Docker Compose based setup

## Tech Stack
- Java, Spring Boot, Spring REST, Spring Data JPA
- React, JavaScript
- MySQL, Redis
- Docker Compose
- Stripe API, Google OAuth 2.0
- Git & GitHub

## Architecture
The project is organized around UI, authentication, common data, payment and search-suggestion services.

## Run
Configure the required environment variables, then:

```bash
./start-all.sh
```

Stop services with:

```bash
./stop-all.sh
```

> Keep credentials, API keys and OAuth secrets out of source control.
