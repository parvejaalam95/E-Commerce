# E-Commerce Platform

A full-stack e-commerce application demonstrating Java/Spring backend development with a React frontend.

## Key Features
- Product catalog with search, filtering, sorting and pagination
- User authentication and Google OAuth 2.0
- Shopping cart and order management
- MySQL persistence with Spring Data JPA
- Redis-based caching
- Stripe payment integration
- Responsive frontend
- Docker Compose based setup

## Tech Stack
- Java
- Spring Boot
- Spring REST
- Spring Data JPA
- React
- MySQL
- Redis
- Docker Compose
- Stripe API
- Google OAuth 2.0
- Git & GitHub

## Architecture
The project is organized around UI, authentication, common product/order data, payment and search-suggestion services.

## Getting Started

Configure the required environment variables using the provided environment template, then run:

```bash
./start-all.sh
```

Stop the services with:

```bash
./stop-all.sh
```

> Never commit API keys, passwords, OAuth credentials or other secrets to source control.
